# yt-shorts

Use only the supplied timestamped transcript. Select complete 20–55 second moments with a clear turn and ending; retain timecodes and transcript language. Validate `.codex/youtube/voice.md` with `.codex/youtube/voice_profile.py`. Draft a distinct first line and on-screen text, and use sibling `hookscore.py` for Telugu or English hooks. Mark uncertain timing instead of guessing. This skill does not edit media or publish.
